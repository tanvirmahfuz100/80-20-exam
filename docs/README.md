# 80/20 Exam Platform

A premium educational platform designed to help students master competitive exams (BCS, SAT, HSC, SSC, etc.) using the 80/20 principle.

## 🚀 Unified Modern Architecture
The project is now running in fully local testing mode with JSON files and localStorage.

- **Frontend**: React + Vite + Tailwind CSS
- **Data Source**: Local JSON files in `public/`
- **Persistence**: Browser localStorage
- **Design**: Premium "Gamer-Tier" Dark UI with smooth micro-animations

## Project Structure

- `/src`: The core application code (Pages, Components, Context)
- `/public`: Static JSON assets for questions and lessons

## Current Mode

1. **No external database**.
2. **No external auth service**.
3. **All app data uses local JSON + localStorage**.
4. **Full-access testing for every user**.

## Getting Started

```bash
npm install
npm run dev
```
