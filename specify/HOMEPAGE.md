# Specification Document: Homepage

## 1. Overview
Homepage is the most crucial part of the app because this will the user see most of the time.

From home page they will navigate to different options, subjects, chapters.

## 2. Customization

Homepage will have a default view but they can be customized by users. We will give some pre-defined structures. These structure defines the position of the components.

### 2.1 Default Structure
- **First segment** - Subject Lists Grid Icons
- **Second Segment** - Daily Quiz Card
- **Third Segment** - Analytical Dashboard Short Version (with a button to view in details)

### 2.2 Configuration Rules
The users will be able to configure the cards, add more cards if they want or remove from the settings. This homepage setting should be available on both Settings Menu and home page itself with a customization icon.

Users can add cards. But remember, cards should not repeat. If there are subject card already, no way to add another same thing.

## 3. Available Cards

There can be more additional card:

- **Leaderboard Card** : showing top 5 position holders - daily, weekly, monthly
- **Star Review Card** : automatically opened one for today's review of the star questions. If no star questions, this card will just be invisible.
- **Challenge Cards** : showing the Daily, weekly, monthly challenges to the user
